# pocket-voice

Claude Code reads its responses aloud using [Kyutai Pocket TTS](https://github.com/kyutai-labs/pocket-tts). The model runs locally on the CPU.

- When Claude finishes a turn, the response is spoken. Code blocks, URLs, tables markup and `file:line` refs are skipped.
- Sending a new prompt stops any speech still playing.
- `/pocket-voice:voice-stop` stops the current speech.
- `/pocket-voice:voice-toggle` turns voice off or on.

## How it works

`scripts/voiced.py` is a background daemon that keeps the model in memory. It is started on demand and exits after 30 minutes idle. The hooks talk to it over `~/.cache/claude-voice/voice.sock` through `scripts/speak.py`. Text is spoken sentence by sentence: the next sentence is generated while the current one plays.

Requires macOS (`afplay`) and [uv](https://docs.astral.sh/uv/). The first run downloads PyTorch and the model.

## Install

```sh
claude plugin marketplace add matiomacedo/pocket-voice
claude plugin install pocket-voice@pocket-voice
```

## Keys

Add to `~/.claude/keybindings.json`:

```json
{
  "bindings": [
    { "context": "Chat", "bindings": {
      "ctrl+x s": "command:pocket-voice:voice-stop",
      "ctrl+x v": "command:pocket-voice:voice-toggle"
    } }
  ]
}
```

## Options

- `CLAUDE_VOICE`: voice name, read when the daemon starts. The default is `alba`. Others include `marius`, `jean`, `eve`, `george`, `jane`, `michael` and `vera`.
- Debug log: `~/.cache/claude-voice/daemon.log`.
